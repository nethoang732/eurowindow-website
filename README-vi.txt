EUROWINDOW — WEBSITE CỬA NHÔM KÍNH

Mở bản xem trước trên Windows
1. Giải nén toàn bộ thư mục website vào máy.
2. Cài Node.js nếu máy chưa có.
3. Nhấp đúp vào file Mo-website.bat.
4. Website sẽ mở tại http://localhost:4173.
5. Để tắt máy chủ xem trước, đóng cửa sổ dòng lệnh có tên Eurowindow preview server.

Website gồm trang chủ, giới thiệu, danh mục và chi tiết sản phẩm, hệ nhôm,
dự án, tin tức, liên hệ, báo giá và trang 404. Ảnh trên website là ảnh minh họa.

Lưu ý: Form báo giá hiện chưa kết nối cơ sở dữ liệu hoặc email. Khi gửi biểu mẫu,
website sẽ thông báo kênh liên hệ trực tiếp thay vì giả báo đã lưu yêu cầu.
Thông tin kỹ thuật, dự án minh họa và nội dung giới thiệu cần được doanh nghiệp
duyệt lại trước khi sử dụng chính thức.

Thông tin liên hệ đã đối chiếu trên trang liên hệ chính thức tại website tham kh?o.
